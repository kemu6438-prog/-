## M0 で最初にやること（着手の順）

1. `pnpm create vite`（vanilla-ts）で雛形を作り、three と `3d-tiles-renderer` を入れる（バージョンは固定）。
2. PLATEAU カタログ API から東京の LOD1 の URL を取得し、`TilesRenderer` で表示（CORS・Draco の確認）。
3. `LoadRegionPlugin` で範囲を絞り、読み込みタイル数・転送量・メモリを計測してログに出す。
4. DEM PNG タイル→地形メッシュ、EGM2008 でジオイド補正、建物底面との差を計測（参考実装は中央値 −0.29 m）。
5. 浮動原点の付け替えを実装し、1 フレームで継ぎ目なく動くことを確認。
6. 結果を `docs/05-spike-results.md` にまとめ、仕様書の前提を更新。

## 進め方

- 各 MS の終わりに、スクリーンショット／短い動画と計測値（FPS・最長フレーム）を `docs/` に残す。
- 判断が分かれる点は「仕様書の未決事項」に積み、決まったら仕様書を更新（変更履歴を残す）。
