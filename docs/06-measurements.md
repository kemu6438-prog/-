# 06. 性能チェック結果（2026-10-08）

公開ページ https://kemu6438-prog.github.io/-/ （性能チェック用の仮ページ）で、依頼者が測定。
負荷ボタンは「重い」（箱 80,000 個、影なし・テクスチャなし・単純な光のみ）を選択した状態のスクリーンショット。

| 項目 | PC（ThinkPad・内蔵 GPU） | Pixel 9a |
| --- | --- | --- |
| コマ数 | 60 コマ/秒 | 60 コマ/秒 |
| 最長の 1 コマ | 17 ms | 20 ms |
| 描画方式 | WebGPU | WebGL 2（WebGPU にならず互換方式） |
| GPU 表示 | ANGLE (Intel HD Graphics, Direct3D11) | Mali-T760, or similar（※ 実機は Mali-G715。ブラウザが名前を伏せている） |
| 画面の大きさ | 1920×1000 | 621×1173 |

## 読み取り

- **単純な箱 8 万個なら、PC も Pixel も 60 コマ/秒を維持できた。** 重い設定でも余裕がある可能性が高い。
- ただし **60 は上限かもしれない**。画面の更新が 1 秒 60 回の場合、それ以上は表示されない（最長 17 ms = 1/60 秒と一致）。余裕がどれだけ残っているかは、この測定では分からない。
- この仮ページは影・テクスチャ・光のにじみ・雨・本物のデータ読み込みを含まない。**本番の街は確実にこれより重い。** 次の段階で、重い要素を 1 つずつ足して測る。
- Pixel 9a が WebGPU でなく WebGL 2 になっている。使用ブラウザ・バージョンの確認が必要（Chrome 最新版なら WebGPU になる見込み）。WebGL 2 でも動くので支障は小さい。
- PC の GPU は Intel の内蔵 GPU（NVIDIA/AMD ではない）と確認。
