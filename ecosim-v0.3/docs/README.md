## 30秒サマリ

- **何を作るか**: プレイヤーが地形・気候・初期生物を決め、放たれた生物が
  ①ニューラルネットの脳で行動し ②生涯学習で個体として適応し
  ③世代交代と遺伝子変異で集団として進化していく 3D 生態系シミュレーション
- **技術**: TypeScript + Three.js（WebGL2）+ Vite + React。
  シミュレーションは Web Worker 内で DOM 非依存に走る（＝Node でヘッドレス実行して自動バランス調整できる）
- **進化の中核**: 形態GA（60遺伝子座）＋ 固定トポロジー MLP 脳（H=12、重み696が遺伝する）
  ＋ 3-factor Hebb 生涯学習。`brainSize` と `plasticity` も遺伝するので**学習能力そのものが進化する**
- **プレイヤーの力**: 地形ブラシ／気候スライダー／クリーチャーエディタ／
  隕石・寒波・疫病などのイベント／**選択圧スライダー**／保護区・壁による地理的隔離
- **規模**: 個人プレイ前提。標準 3,000 体 @60fps、上限 8,192 体
- **開発**: Phase 0（足場）→ 1（生態系の心臓）→ 2（遺伝と形態進化）→ 3（脳と学習）
  → 4（プレイヤーの力）→ 5（磨き込み）→ 6（共進化などの拡張）。
  **各 Phase の終わりは必ず「遊べる状態」**

## 設計上の最重要判断（迷ったらここを見る）

1. **物理エンジンを使わない** — 地形高さ吸着＋半径判定の押し出しだけで数千体を回す
2. **SoA（Float32Array）で個体を持つ** — object 配列は GC で必ず詰む
3. **NN はトポロジー固定（H=12）** — 可変長にするとゲノム・メモリ・交叉が全部壊れる。
   `brainSize` は「有効ユニット数」と「代謝コスト」で効かせる
4. **sim は DOM 非依存** — ヘッドレスで100年×32パターンを回して数値を自動調整する
5. **植物は v0.1 では進化しない** — ただしこれが最重要の拡張候補（Phase 6 の共進化）
