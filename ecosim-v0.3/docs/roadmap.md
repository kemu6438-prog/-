# 開発ロードマップ / タスクリスト v0.1

> 各 Phase の終わりは「必ずブラウザで遊べる状態」にすること。
> 見積りは個人開発・週 10〜15 時間想定の目安（±50%）。
> チェックボックスは実装しながら更新する。

**進行ルール**
1. 新しい Phase に進む前に、前の Phase の「受入基準」を満たす
2. 数値は必ず `docs/parameters.md` に書き、コードに直書きしない
3. sim 側コードは DOM / Three.js を import しない（ヘッドレス実行可能性を守る）
4. 各 Phase 終了時に 100 ゲーム年のヘッドレス実行をして、個体群が崩壊していないか確認する

---

## Phase 0 — 足場（1〜2週）

### 環境
- [ ] `npm create vite@latest ecosim -- --template vanilla-ts`
- [ ] 依存: `three`, `react`, `react-dom`, `zustand`, `uplot`, `tailwindcss`, `nanoid`
- [ ] `tsconfig` を strict + `noUncheckedIndexedAccess`
- [ ] ESLint / Prettier
- [ ] `src/sim` を import するだけの Node スクリプト（`headless/runBatch.ts`）が通ることを確認

### 基盤
- [ ] `Rng.ts` — xorshift128+、`fork(streamId)` で派生ストリーム生成
- [ ] `SoA` ストアのヘルパ（空きスロット管理 `FreeList`）
- [ ] `sim.worker.ts` + `protocol.ts` の疎通（ping/pong, transferable 実測）
- [ ] tick ループの骨格（`requestAnimationFrame` → worker へ `tick` コマンド）

### 描画
- [ ] `Renderer.ts` — シーン、 PerspectiveCamera、 DirectionalLight + HemisphereLight
- [ ] カメラリグ（WASD / 右ドラッグ回転 / ホイールズーム、地形にめり込まない）
- [ ] `TerrainMesh.ts` — fbm ノイズ heightmap → 8×8 チャンク mesh、テクスチャスプラッティング簡易版
- [ ] 水面プレーン
- [ ] 空（gradient or HDR env）

### 受入基準
- [ ] ランダム生成された島が 60fps で描画され、カメラで自由に飛び回れる
- [ ] シードを変えると地形が変わり、同じシードで完全に同じ地形が出る
