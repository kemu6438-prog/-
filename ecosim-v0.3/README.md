# ECOSIM（仮）— v0.2（Phase 0〜2 の一部 ＋ Phase 4 の一部）

設計書は `docs/`（spec.md / parameters.md / roadmap.md）。

## 公開（GitHub Pages）

`.github/workflows/deploy.yml` が `main` への push で `npm run build` を実行し、`dist/` を GitHub Pages に公開します。
リポジトリの Settings → Pages で Source を **GitHub Actions** に設定してください。`vite.config.ts` は `base: './'` なので、サブパスでも動きます。

## 起動

```bash
npm install
npm run dev        # ブラウザで http://localhost:5173
npm run build      # 型チェック + 本番ビルド
npm run headless -- --years 100 --seeds 3   # DOM なしで生態系を回し、個体群を集計
```

## 操作

| 入力 | 動作 |
|---|---|
| 左クリック（観察） | 個体を選択 → 右パネルに形質を表示 |
| 🔥 山火事ツール | クリック／ドラッグで草を焼く（半径は左パネル） |
| 🐾 草食獣を放す / 🦁 肉食獣を放す | クリックで草食獣 10 匹 / 肉食獣 3 匹を放す |
| 左パネル「気候」 | 気温補正・降雨・季節の振幅・捕食圧をスライダーで変える |
| 左パネル「災害・イベント」 | 寒波・熱波・干ばつ・豪雨は即時。隕石・疫病は地図上のクリックで発生 |
| 右ドラッグ / ホイール | 視点回転 / ズーム |
| WASD・QE（Shift で高速） | 視点移動 |
| 上部の速度ボタン | 一時停止 / 0.25× / 1× / 4× / 16× / 64× |

## 構成

```
src/sim/       シミュレーション本体（DOM / Three.js 非依存）
  predators.ts 肉食獣（SoA。狩り・水飲み・休息・求愛）
  config.ts    数値定数（parameters.md から取り込み。(補正) は調整値）
  rng.ts       決定論的乱数（xorshift128）
  noise.ts     地形・気候用の fbm ノイズ
  world.ts     地形・気候・バイオーム・草（成長・焼失）・水までの距離
  agents.ts    草食獣（SoA配列、FSM: うろつき/採食/水飲み/休息/求愛、繁殖、死亡）
  sim.ts       Simulation：step・日次記録・介入・スナップショット
  protocol.ts  Worker ⇔ UI の型
src/worker/    sim.worker.ts（シミュレーションをメインスレッドから分離）
src/render/    viewer.ts（Three.js：地形・水・草の色・InstancedMesh の草食獣・選択）
src/main.ts    HUD（操作・統計グラフ・個体インスペクタ・イベントログ・全滅レポート）
src/headless/  runBatch.ts（ヘッドレス実行・バランス確認）
docs/          設計文書一式、parameters.md 付録（v0.2 追加値）、100年検証ログ
```

## 仕様からの主な逸脱（理由つき）

1. **エネルギー・移動コストの係数**：parameters.md の式（`/86400` 等）のまま使うと、基礎代謝と移動コストの桁が合わず、どの個体も数日で餓死した。`ENERGY_SCALE`・`MOVE_COST_SCALE` などで補正（`(補正)` 表記）。
2. **エージェント更新を 4 tick ごと（1/15 秒）に**：性能優先。描画・入力は毎フレーム。
3. **採食量・繁殖間隔の補正**：増殖が速すぎて草が追いつかず、1〜2年で崩壊したため（`MATE_COOLDOWN_DAYS` 5→20 など）。
4. **FSM の優先順位にヒステリシス**：水飲み⇄採食の往復で餓死が起きたため、水飲みは水分75まで完遂する。
5. **水辺の制約**：草の目標は陸地のみ、泳いでいたら陸へ戻る（水辺で泳ぎ続けて餓死する個体が多発したため）。
6. **UI は React/zustand/uPlot を使わず素の DOM＋Canvas**：Phase 1 の規模では依存を増やさない判断。
7. **data-model.ts は添付されていなかったため未使用**（型は `src/sim/protocol.ts` と各モジュール内に定義）。
