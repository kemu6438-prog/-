# 街ドライブビュー（仮称）

車が街中を走る様子を、**リアルタイムにシミュレーションして、リアルタイムの 3D 映像として眺める**ブラウザゲーム。

参考: [kexi/tokyo-od-game](https://github.com/kexi/tokyo-od-game)（東京 23 区を PLATEAU 3D 都市モデルで走る three.js ゲーム）
